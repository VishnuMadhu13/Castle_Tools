## Key Files Explained

### `lib/auth.ts`
NextAuth configuration — Google provider setup, JWT callbacks to attach `isAdmin` and `id` to the session.

### `lib/gmail.ts`
Gmail API helper that constructs a raw RFC 2822 message with `X-Gm-Confidential-Mode: 1` header and sends it via `gmail.users.messages.send`.

### `lib/crypto.ts`
AES-256-GCM encryption/decryption using Node.js `crypto` module and `CREDENTIAL_ENCRYPTION_KEY` from env.

### `middleware.ts`
Protects `/dashboard` and `/admin` routes. Redirects unauthenticated users to `/`. Admin check inside `/admin/layout.tsx`.

### `db/schema.ts`
Single source of truth for all Drizzle table definitions.
